# HOLORACT: Immersive STEM Education Through Gesture-Controlled Holographic Projections

HOLORACT is an interactive STEM education project that combines gesture recognition, computer vision, and holographic projections to create immersive learning experiences. It enables users to interact with virtual 3D objects using hand gestures captured through a camera.

## 🚀 Project Overview

HOLORACT aims to make STEM education more engaging and accessible by allowing students to visualize and interact with 3D concepts through gesture-based controls.

## ✨ Key Features

- Real-time hand tracking and gesture recognition
- Interactive 3D visualizations for STEM education
- Camera-based gesture input using computer vision
- Low-cost holographic projection setup
- Immersive and interactive learning experience

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- React
- Three.js / WebGL

## 📊 Performance

- Gesture recognition accuracy: 94%
- Real-time performance: up to 60 FPS
- Average latency: approximately 68 ms

*Performance figures are based on project testing.*
